5. Conclusions & Future Work

Key contributions: A General NeSy framework supports:

1

Four encoding methods

One-hot Index-based Shrinked Index-based Multi-enocders
2

Two neural models

LSTM Transformer
3

Multiple BK types

Declare MP-Declare Probabilistic Declare Procedural model (BPMN, Petri Nets)
4

Various predictions modes

Beam search Greedy search Pure neural predictions Post-predictions BK filtering (BK-filter) Contextualized prediction with BK (Bs-BK)
5

Multi-attribute suffix prediction

Activity prediction Activity and resource prediction
6

NeSy4PPM library for practical implementation

Open source Pypi

Future directions

1
Extend evaluation to more real-world event logs
2
Investigate impact of probabilistic declarative BK during suffix prediction
3
Extend framework to support fuzzy declarative models for handling uncertainty
4
Extend framework to incorporate BK during the training via loss function
