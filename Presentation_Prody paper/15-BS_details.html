3.2 Prediction Layer

search

BK-contextualized prediction steps:

1
ExpandBranches: Extends each prefix with all possible activity-resource pairs by computing:
- $\color{blue}{\mathrm{NN}(\langle \sigma, (a, r) \rangle)}$: NN probabilities of each activity-resource pairs
- $\color{orange}{\mathcal{C}(\langle \sigma, (a, r) \rangle,\mathcal{BK})}$: Compliance with BK:
  • Declare
  • MP-declare
  • Probabilistic Declare
  • Procedural model (petri nets, BPMN)
  • Fuzzy
2
Score Calculation: Combines NN probabilities with BK compliance
\[ score_{\langle \sigma, (a, r) \rangle} = score_{\sigma}\cdot \color{blue}{\mathrm{NN}(\langle \sigma, (a, r) \rangle)}\color{red}{^{1-w}}\cdot \color{orange}{\mathcal{C}(\langle \sigma, (a, r) \rangle,\mathcal{BK})}\color{red}{^w} \]
3
TopRank: Selects highest scoring branches for next iteration
4
Returns the top compliant suffix that reaches termination
